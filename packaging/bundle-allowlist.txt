# under Star Wars Chess.app. scripts/check-installed-app.sh reads this list
# and fails when the bundle holds a file that is not here. A listed file that
# is missing is fine, because the bundle changes as helpers come and go.
#

# the release. An icon made from the CD logo would pass a check that only
# looks at file extensions, so name every file instead.

Contents/MacOS/swchess-extract
Contents/MacOS/swchess-interpolate
Contents/Resources/StarWarsChess.icns
Contents/Frameworks/libSDL3.0.dylib
Contents/_CodeSignature/CodeResources
