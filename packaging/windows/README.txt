Star Wars Chess
===============

How to play
-----------

1. Unzip this folder anywhere you like. Your Desktop or your Documents
   folder both work. Keep every file together in the same folder.
2. Open the folder and double-click "Star Wars Chess.exe".

The game needs no installer and it writes nothing into Program Files.
To remove it, delete the folder.


The warning Windows shows the first time
----------------------------------------

Windows may show a blue box that says "Windows protected your PC". This
happens because nobody paid Microsoft to sign the program, not because
anything is wrong with it.

Click "More info", then click "Run anyway". Windows remembers your answer
and stops asking.


Where your settings and saved games go
--------------------------------------

The game writes them to this folder:

    %APPDATA%\FairLine\Star Wars Chess

Paste that path into the address bar of File Explorer to open it. Delete
that folder to reset the game to how it started.


The other program in this folder
--------------------------------

swchess-viewer.exe replays a recorded game. You do not need it to play.
